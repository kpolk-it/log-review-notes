# Log Review Notes

Beginner-friendly notes for reviewing common Windows security events during alert triage.

This project is intended to help with first-pass investigation, documentation, and escalation decisions.

## Purpose

- Explain common Windows Event IDs in plain language
- Show what an analyst should check next
- Separate likely noise from events worth escalating
- Support SOC and security operations learning

## How This Relates to SOC Work

SOC analysts often start with a log or alert and need to answer:

- What happened?
- Who or what was involved?
- Is this expected?
- Does this need escalation?

These notes are written for that first-pass review.

- False positive notes
