# Example: New Account Created

**Scenario:** A 4720 event shows a new user account was created.

### What Was Reviewed
- Account name
- Who created it
- Time of creation
- Whether a ticket or expected request existed

### Findings
- Account was created outside normal business hours
- Creator was an admin account
- No matching request was found during initial review

### Decision
Escalated for verification. Requested confirmation that the account was approved and that group membership is appropriate.

### Why This Matters
New account creation is not always malicious, but it should be expected and documented.
